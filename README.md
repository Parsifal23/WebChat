# WebChat
Simple client-server app with multiuser chat

# Download
git clone https://github.com/Parsifal23/WebChat.git

# Description
Появилось желание разобраться в том, как работать с сокетами, базами данных, пулом потоков. Так и родилась идея создать простой чат с несколькими пользователями, возможностью сохранять историю в базу данных.
На текущий момент имеется возможность принудительного выбора пользователя в качестве собеседника, чтобы был виден диалог в чате.
Возможны некоторые визуальные недочеты. Но со временем всё усовершенствую. Соединение сервера и клиента локальное.

# Requirements
Qt Creator 5 и выше

# Using
Необходимо в отдельных окнах Qt Creator запустить проект сервера из папки Server и как минимум 2 клиента из папки Client. Т.е. будет 3 окна: в одном - сервер, во втором - клиент, в третьем - тоже клиент.
Сначала запускаете проект сервера. В выводе приложения в Qt Creator должен появится текст Server started. Затем по очереди запускаете проекты клиентов. 
В графическом окне клиента вводите придуманный ник для чата. Разумеется, ники клиентов должны быть разные. И нажимаете "Подключиться" в каждом окне.
Затем в каждом окне в списке пользователей необходимо дважды щелкнуть на пользователя для выбора собеседника. В обоих клиентах выбор пользователей должен образовывать пару. Т.е. User1 выбирает User2, а User2 выбирает User1. Затем можно писать сообщения.
