# WebChat

Простой клиент-серверный чат на C++/Qt с использованием TCP-сокетов.

Проект создан для практического изучения:

* работы с TCP-сокетами;
* клиент-серверной архитектуры;
* `QDataStream`;
* обработки входящих сообщений;
* работы с несколькими клиентами;
* управления подключёнными пользователями;
* организации пула потоков и базы данных — в планах развития проекта.

> Проект находится в разработке, поэтому некоторые части приложения пока реализованы не полностью.

## Возможности

На текущем этапе реализованы:

* локальное TCP-соединение между клиентами и сервером;
* подключение нескольких клиентов к одному серверу;
* выбор имени пользователя (username);
* автоматическое обновление списка подключённых пользователей;
* выбор собеседника двойным щелчком мыши;
* отправка сообщений выбранному пользователю;
* отображение даты и времени сообщения;
* уведомление о новом сообщении от пользователя, с которым в данный момент не открыт диалог.

История переписки и сохранение сообщений в базу данных пока не реализованы.

### Server

Сервер принимает TCP-подключения клиентов и хранит соответствие между сокетом и username:

```text
QTcpSocket* → Username
```

Сервер также:

* принимает сообщения от клиентов;
* обновляет список пользователей;
* определяет получателя сообщения;
* пересылает сообщение соответствующему клиенту.

Сервер запускается на:

```text
127.0.0.1:1234
```

### Client

Клиент отвечает за:

* подключение к серверу;
* регистрацию username;
* отображение списка пользователей;
* выбор собеседника;
* отправку сообщений;
* отображение входящих сообщений.

## Формат сообщений

Для передачи данных между клиентом и сервером используется `QDataStream`.

Каждое сообщение содержит:

1. размер блока;
2. тип сообщения;
3. данные сообщения.

Типы сообщений определяются перечислением:

```cpp
enum class _EnMessageTypes {
    enSaveUsername = 1,
    enUpdateUserList,
    enChatMessage,
    enSelectHistoryDb
};
```

`enSelectHistoryDb` зарезервирован для будущей реализации загрузки истории переписки из базы данных.

## Запуск

Для работы приложения необходимо запустить один сервер и как минимум два клиента.

### 1. Запуск сервера

Откройте проект сервера из каталога `Server` в Qt Creator и запустите его.

В выводе приложения должно появиться:

```text
Server started.
```

### 2. Запуск клиентов

Откройте проект клиента из каталога `Client`.

Запустите как минимум два экземпляра клиента.

В итоге должно быть открыто минимум три окна:

```text
┌─────────────────┐
│     Server      │
└─────────────────┘

┌─────────────────┐
│     Client 1    │
└─────────────────┘

┌─────────────────┐
│     Client 2    │
└─────────────────┘
```

### 3. Подключение клиентов

В каждом окне клиента:

1. Введите уникальный username.
2. Нажмите **«Подключиться»**.

Username клиентов должны отличаться.

После подключения пользователи появятся в списке пользователей.

### 4. Выбор собеседника

Дважды щёлкните по username пользователя, которому хотите написать.

После выбора собеседника становится доступна отправка сообщений.

Например:

```text
Client 1: User1
Client 2: User2

User1 → User2
```

После выбора `User2` в первом клиенте можно отправлять ему сообщения.

> В текущей версии выбор собеседника является локальным состоянием клиента. Получателю не требуется выбирать отправителя для самого TCP-соединения — выбор собеседника влияет на то, какой диалог отображается в интерфейсе.

## Требования

* Qt Creator 5 или выше
* Qt с поддержкой `QTcpServer`, `QTcpSocket` и `QDataStream`
* C++ compiler, поддерживаемый используемой версией Qt

## Установка

```bash
git clone https://github.com/Parsifal23/WebChat.git
```

После клонирования откройте соответствующие проекты `Client` и `Server` в Qt Creator.
